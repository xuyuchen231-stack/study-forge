# Source intake and learning packs

1. Inventory each input with a stable source ID, title, edition/date if visible, and available locators. For video, use an available transcript and timestamp. For scanned pages, attempt available OCR or page inspection and flag uncertain text. Inspect equations, tables, figures, and answer keys visually when extraction is unreliable.
2. Map the contents into concepts. Record prerequisites, mechanisms, decision rules, boundary conditions, worked examples, and common errors. Preserve distinctions between similar terms. When sources disagree, report both claims with scope, date, and evidence. Avoid inventing a synthesis where none is supported.
3. For Q&A, find the relevant concept, retrieve the minimum matching sections, and verify claim-to-source alignment. Cite e.g. `S1, ch. 3, PDF p. 41` or `S2, §2.4`. Distinguish printed and PDF page numbers when both matter. If a conclusion requires a calculation, present the inputs and verify the result separately.
4. For a persistent pack, write an `index.md` routing topic → concept files, a `sources.md` manifest, and focused `concepts/<slug>.md` notes. Add glossary, decision tables, or self-test items when useful. Give each concept an objective, prerequisites, explanation, application and failure conditions, and references. Store answer keys separately so practice can run blind. Keep learner notes outside the pack. Load only the relevant files on later turns.
5. When the learner explicitly requests an installable subject skill, also produce a compact `SKILL.md` that routes questions to the notes and preserves locator rules. Validate the name/frontmatter, relative links, source coverage, and one sample lookup. Report whether the result is a study pack, installable source, or a verified installation.
6. For updates, identify changed sources, revise affected concepts and locators, and keep stable concept IDs for progress records. Preserve meaningful disagreements. Do not publish textbooks, private notes, or their substantial reproductions. Use short quotations only when necessary.
