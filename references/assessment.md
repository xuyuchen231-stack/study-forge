# Assessment and mastery

Before writing each item, choose a concept ID, one skill to measure, a difficulty, an expected answer with rationale, and a rubric. For multiple choice, ensure one defensible answer and use distractors tied to real misconceptions. For a calculation, solve independently and check units and numerical tolerance. Flag ambiguities in supplied exam items before scoring.

In live mode, ask one item at a time unless a full set is requested. Give feedback after the attempt. Distinguish conceptual errors, prerequisite gaps, setup errors, slips, and correct guesses. Offer one increasingly specific hint at a time. If a learner asks for a full solution, show the reasoning and offer a parallel problem. If a hint or key was seen, record the attempt as assisted.

Track evidence per concept rather than time spent:
- **Unseen** — No observed attempt.
- **Developing** — Partial or assisted success.
- **Independent** — Correct unaided explanation or application.
- **Transfer** — Correct unaided application in a meaningfully changed scenario.

Keep a minimal checkpoint with concept ID, status, last attempt, observed error or evidence, and next review target. On resume, start with a brief retrieval item for the weakest prerequisite or a due concept. Use one shorter review interval after a miss and a longer one after repeated independent successes. A review date in the record is a suggestion unless an actual reminder has been requested and scheduled. If no durable record is available, give the learner a copyable checkpoint.
