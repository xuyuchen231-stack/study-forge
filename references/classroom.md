# Interactive classroom

Open with a real question, a performance goal, and a brief path. Select only the scenes that advance the goal.

| Scene | What to produce |
| --- | --- |
| Explain | A short model of how the idea works, a concrete example, and a boundary case |
| Whiteboard | A diagram, equation walkthrough, timeline, or comparison with a single purpose |
| Discussion | A plausible student misconception, a competing explanation, and a prompt that asks the learner to decide |
| Simulate | A clear model with assumptions, adjustable inputs, measured outputs, and a prediction prompt before showing the result |
| Check | An unaided question, response pause, targeted feedback, and a new retry when needed |
| Project | A realistic brief, constraints, milestones, deliverable, evidence standard, and rubric |

Use a teacher to explain, a peer to surface a misconception, and a reviewer to check the reasoning when those roles add value. Label role-play clearly and keep the learner in control. Avoid writing both sides of the learner's turn. For a requested simulation, show what is simulated, give units, and check extreme inputs. If an executable visual is unavailable, walk through two contrasting cases.

For a project, show only the current milestone and criteria in live mode. Compare the learner's result with the rubric before moving on. For a full course artifact, include lesson objectives, source references, practice prompts, and a separate answer key. Create slides or an interactive artifact only if requested or materially helpful and the host supports it.
